# v0.80.1 — 2026-10-12

This patch release publishes gpt-gateway, the local gateway the GPT twin agents need, and pins it as a submodule of this repository. Nothing in pfm, the machine-global templates or the project templates changes at runtime, so an adopter who does not use the GPT twins has nothing to do.

## Added

- Repo: gpt-gateway — the local gateway the GPT twins (`gpt-foreman`, `gpt-foreman-pro`, `gpt-lander`, `gpt-executor`, `sol`, `luna`, `terra`, `astra`) need is published at <https://github.com/rezzminator/gpt-gateway> (v0.1.0) and pinned as the `plugins/gpt-gateway` submodule; `README.md` and `docs/design/gpt-twins/gpt-twins.md` point at it.
#### → For: adopters who use the GPT twins · after update · gpt-gateway — install it from its repository per its README (on macOS, `launchd/install.sh`); a host running a former private `model-gateway` install is migrated by that same `install.sh`; `~/.local/share/gpt-gateway/ctl.sh status` then prints `state:  on`.
