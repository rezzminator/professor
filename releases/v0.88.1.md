# v0.88.1 — 2026-11-14

A chat pfm hosts in tmux no longer closes the terminal it was opened from: type `claude`, `codex`, `cx` or the `pfm` picker into a terminal outside Herdr, and when the chat ends or you detach it the shell gets its prompt back, so leaving a chat over ssh no longer drops the connection. The `pfm internal exit-close` SessionEnd hook behind it is gone; the update's `pfm install` strips it from your settings, and a chat started before the update ends quietly. Shells already open keep the old shell functions until you restart them, which is the one action this release asks for.

## Changed

- Repo: plugins — forward-compaction is pinned at its 2.3.1 release: opening a sub-agent from the agent list folds its compaction wake too, instead of drawing its facts and handoff whole under "From main".

## Fixed

- pfm: shell shim — a harness typed into a terminal outside Herdr (`claude`, `codex`, `cx`, or the `pfm` picker) runs on tmux as the shell's child, and the chat ending or being detached hands that shell its prompt back; before, the SessionEnd hook detached the tmux client and hung up the shell it ran under, which on an ssh login closed the connection, and a plain local terminal or VS Code tab outside the bunker closed with the chat. Only a Herdr pane or a VS Code bunker pane still closes when its harness ends. The shim is sourced from the clone, so every new shell has it once the clone moves; a shell opened before the update keeps the old functions until it restarts.
#### → For: every adopter · after update · open zsh shells — in each terminal opened before the update, run `exec zsh` (or open a new terminal), then `type _pfm_in_herdr_pane` prints `_pfm_in_herdr_pane is a shell function`.

- pfm: exit-close hook — the SessionEnd hook `pfm internal exit-close` is deleted and its name joins the retired hook commands in `templates/global/retired.json`: the update's `pfm install` strips it from any account settings file still holding it, `pfm doctor` reports any copy left, and a chat started before the update that still holds the hook runs it as a silent no-op that exits 0, so nothing is detached when that chat ends. A Claude chat carries one fewer hook (24 registrations).
