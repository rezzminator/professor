# professor

Claude Code plugin for Professor's terminal look: it draws each sub-agent's row in the agent list as one instrument strip, the same columns at the same cells in every row, so a glance down a column compares the agents.

```text
◯ 1/3 ▰▱▱▱▱▱▱▱ ••••••••   +4.5K  17% 171.9K/1.0M   │ planner              │ ◆ opus·▰▰ medium  │ running 12m04s │ Σ $3.41 · 2.0M in · 24.3K out · 57 tools   │ 💾5m✓3m08s 94%     │ 2 errors │ ⟲1 │ Map the parser › Reading lexer.go
└ ◯      ▰▱▱▱▱▱▱▱ ····•↓  −22.0K   5%   9.0K/200.0K │ Explore              │ ○ haiku           │ done           │ Σ $?                                       │ 💾– ?%             │ pfm ✗ open agent-a3.jsonl: permission denied │ Find the callers
◯      ▰▰▰▰▰▰▰▱ ················· 86% 172.9K/200.0K │ door·flights:foreman │ ◇ sonnet·▰▰▰ high │ running 1m01s  │ Σ $12.50+? · 812.0K in · 9.3K out · 1 tool │ 💾5m✗1m40s was 31% │ idle 3m20s │ @door │ adv $0.30 │ Build the door › Running go test
```

- Agents below: the row opens with the agents below it, working/total (`1/3`), `?/?` when pfm could not list them, `+2?` for those whose state it could not read; the column is as wide as the list's widest count, the rows without one padded to it, and takes no cells when no row of the list has agents below it.
- Gauge and pulse: the gauge's eight cells fill from the left with `▰` for the share of the context window in use (green under 50%, yellow under 80%, red from there), the rest `▱`, dimmed. After a blank, the pulse's six cells are how much the context grew in each engine reading, about five seconds, newest on the right, on one scale for every row: a muted `·` nothing, then `•` from 1 and `●` from 5K tokens, in the growth figure's colour. `↓` marks a reading in which it shrank by 1,000 tokens or more (a compaction); a cell before the agent's first reading is a muted `·`. The newest reading's growth in figures, the share, and tokens over window follow it. A row less nested than the list's deepest draws two more pulse cells a level, older readings on the left, so every row's figure and share sit on the same cells; while there is no growth figure to draw (the newest reading grew nothing, or the form has none) the pulse also runs over the figure's cells and the share's pad, to one blank before the share, which stays on its cell.
- Who: the agent's name and type. Model: its family's symbol and name, the effort bar and level.
- State: running, waiting, idle, pending, paused, done, failed or killed, with the time since it started, or how long it ran.
- `Σ`: dollars, prompt tokens, output tokens and tool calls of the agent and every agent below it; `+?` marks a lower bound, `$?` an unpriced sum.
- `💾`: the prompt cache's lifetime, the time left (`✓`) or since it lapsed (`✗`), and the share of the last prompt read from it; `–` no cached request, `∅` a model that keeps no cache.
- Flags, only when true: `pfm 45s ago` when pfm's facts for the row are that old (its last answer gave none for the agent), `idle` after a minute without a transcript entry, tool errors, `⟲` compactions.
- Notes, where there is room: `@` the working directory when it is not the session's, `adv` the advisor's part of the sum, `API-eq` a sum priced at API rates.
- Then the task and, after `›`, what the agent is doing now.

The second line of pfm's status line is the chat's own row of the same instrument: the same gauge and pulse on the same scale, one cell for five seconds, running over the growth figure's cells and the share's pad the same way, then the share, tokens over the window, `Σ` and `💾` in the same order, units and colours, so the chat and its agents compare by eye.

The engine's row props give the live half; `pfm statusline --agents` gives the rest, the colours, the gauge's and the pulse's glyphs, widths and scale, and the colour thresholds, one call for every agent of the list, running or ended, every four seconds, and the rows are redrawn each second while an agent runs. A fact pfm has not answered yet draws as `…`, one it could not give as `?`. When pfm fails the rows keep the look it last gave; until its first answer, or when it is not on `PATH`, the rows keep the engine's fields without colour, the gauge empty and the pulse quiet, the engine's own dollars marked `own`, the first row names the cause after `pfm ✗` and the others carry the mark.

The terminal's width alone picks the form of the context block every row opens with, from pfm's table of widths (`look.context`), so the rows and the main status line under the same terminal always draw the same form: gauge, pulse, growth figure, share and tokens over window from 120 cells, without the growth figure from 100, without the pulse from 90, the gauge and the share alone below that. A row's width is the terminal's less six cells (Claude Code's footer padding each side and the engine's lead before the row), which the mod adds back before it reads the table. When the terminal is too narrow for the rest, every row gives up the same parts in the same order: first a shorter spelling of the same facts (the sum in slashes, the name cut to 24 cells, the flags' words (`2 err`), the effort's word, the family's name beside its glyph, the task past 20 cells, the name cut to 12 cells), then the padding (the blanks around each bar, then the pad that aligns the columns), only then a fact, least missed first: the sum's counts, the cache's lifetime and hit share, the sum, the cache, the model, the task. The count of agents below, the gauge, the share, who, the state and the flags always stay; a row still too wide ends in `…`. A nested row, which the engine draws under its parent behind a `└` once that agent is viewed, sits on the same cells.

Install with `/plugin install professor --marketplace rezzminator/professor`. Requires function hooks (`CLAUDE_CODE_ENABLE_FUNCTION_HOOKS=1`), Claude Code 2.1.326 or later, and `pfm` on `PATH`. Remove it with `claude plugin uninstall professor@professor`. Logs go to `$PLUGIN_LOG_DIR/professor`, else `~/.local/state/professor/logs`.
