# Wave 8 — close the known gaps; the ledger ships empty

**Law (the user's):** a known issue is fixed, not ledgered. `lanes/known-gaps.yml` stays only as an escape hatch for a failure that cannot be fixed here (an upstream engine bug, hardware we lack): every entry needs `expires:`; past it, or on an unexpected pass, the run is red.

1. **OpenCode MCP wiring** (beats `M.03`, `E3.02`): the installer registers both pfm MCP servers in OpenCode's config the way it does for Claude (stdio/HTTP) and Codex (HTTP); `pfm doctor` gains the OpenCode MCP rows; uninstall removes exactly what it wrote. Tracer-map the three engines' registration doors before the build (map-before-dispatch).
2. **OpenCode compile layer for adopters** (beat `A.13`): `pfm opencode build|check|doctor` is the single writer and validator for the repo and global OpenCode projections; the adopter Stop hook installed by `pfm init` invokes it, and `pfm update check` carries that hook through the project baseline. Touches `templates/**` → through `/pcm`.
3. **harvestpy on linux-arm64** (beat `O.11`): provision and verify the pinned Python sidecar on arm64 (the Mac's fence is linux-arm64 — the test bed exists); if a pinned wheel truly has no arm64 build, that single dependency is the one legitimate ledger entry, with an expiry.
4. **Duplicate seat login** (found 2026-09-17): `pfm doctor` names two seats holding one account (also listed in Wave 3 B5a — built once, here or there, whichever dispatches first).
5. **Self-compact waits on the wrong signal** (beat `E1.20`, found 2026-09-17): the `then` waiter holds while the chat reports `working`, and a chat with running background sub-agents reports `working` — so a self-compact never fires while any background agent runs, and neither the tool result nor the pane says what it waits for. Fix: the waiter waits for the MAIN turn to be idle (sidechains allowed — `/compact` works beside background agents), a second request while one is armed is refused naming the armed one, the waiter logs a first line on start, and the pane shows `compact armed — waiting for: <what>` (the reload-hold notice pattern). Beat: self-compact with a background agent running.
6. **Resolver double-counts one session** (beats `E1.07`, `E1.09`, `E1.20`, `E1.22`, `E1.26`; found live 2026-09-17): `pfm chat inject` refuses with `excerpt is ambiguous between <sid> and <the same sid>` when duplicate transcript registries return one session twice. Candidates are deduplicated by session id before the excerpt ambiguity check; the watched-red regression lives beside the CLI fallback in `cmd/pfm`.
7. **`reload --new` leaves the name behind** (beat `E1.06`, found live 2026-09-17): the fresh session is auto-named from the `--then` steer and the old session keeps the chat's name as a resume row, so every by-name verb reaches the dead session. Owner's ruling pending (recommendation: the name follows the live pane; the row left behind is renamed `<name> (before --new)` or hidden). Until ruled, the lane follows the socket and re-names.
8. **The markdown formatter hook mangles `docs/dev/testing/landscape.md`** (found 2026-09-17): an Edit-tool write triggers `format-md.sh`, which reflows the 429 id rows into paragraphs and demotes headings. The hook must skip machine-read files (a marker line or a path list in `.rumdl.toml`/the hook), and `landscape.md` carries that marker; regression: a formatted copy is byte-identical to the input.

Each fix: regression test watched red first; its lane beat flips from `known` to a real assertion in the same commit; the ledger entry is deleted in that commit.
