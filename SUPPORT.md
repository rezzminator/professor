# Support

- Question or idea: [Discussions](https://github.com/rezzminator/professor/discussions).
- Bug: [open an issue](https://github.com/rezzminator/professor/issues/new/choose) with `pfm version` and the relevant `pfm doctor` output.
- Install or update trouble: [INSTALL.md](INSTALL.md) first, then `pfm doctor`, which checks the dependencies and the fleet database.
- Vulnerability: [SECURITY.md](SECURITY.md) — privately, never in a public issue.

Only the latest release is supported; `develop` carries the next `-alpha`.
