# v0.88.0 — 2026-11-14

Nothing in this release asks anything of you: there is no action before, after or per project. The Herdr indicator daemon, the painter behind Herdr's sidebar state marks and tab status, now rescans the whole fleet once a minute instead of on every change, so it costs far less CPU on a busy host, while a chat's new name or AI title still reaches its tab on the next tick. A painter already running when you update keeps the old code until it exits. A new machine can now install pfm with one command from `INSTALL.md`, and the README shrinks to one screen, with its reference detail moved to `docs/guide/`.

## Added

- Repo: scripts/install.sh — a one-command installer for a new machine: it downloads the latest release's pfm for the OS and architecture, checks it against `SHA256SUMS` and installs it as `~/.local/bin/pfm` (`PFM_VERSION` picks another tag, `PFM_INSTALL_DIR` another directory); `INSTALL.md` names the one-liner, and it has not yet been run on a real macOS machine.

## Changed

- pfm: Herdr indicators — the Herdr indicator daemon rescans the fleet once a minute instead of on every change: between scans it re-reads only the chats and panes whose transcript, engine foreground (read at most every 5 s) or pane state moved, and repaints only tabs that animate, whose state changed or whose last rename did not settle, retrying those on the next tick; a pane added, gone or moved, a mode, glyph or OpenCode title change, or a new AI title or `/rename` appended to a Claude chat's transcript still forces a full scan, so a tab name shows on the next tick, and a failed read is retried, never cached as no tab. On a copy of a busy host's state it went from 23.8 % of one core to about 2.6 % over 60 s. A painter already running when you update keeps the old code until it exits (no blocked or unseen-done agent and no chat tab left, Herdr's server stopping, or `pfm theme off`).
- Repo: README.md — the README is one screen: a hero animation, a quickstart and what ships; its reference detail moves verbatim into `docs/guide/` (fleet CLI, discipline layer, plugins).
