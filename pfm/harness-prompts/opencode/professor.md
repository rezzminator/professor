# OpenCode

- The project contract is the compiled `AGENTS.md`; the `.opencode/` layer holds the compiled agents (`.opencode/agent/*.md`), the commands under their flat names (`/flights-doctor` for `/flights:doctor`) and `opencode.jsonc`, where the generated-file and Git-write denies are pinned. Git writes and framework files (any `CLAUDE.md`, `AGENTS.md`, `AGENTS.override.md` or `opencode.json(c)`, `.claude/`, `.codex/`, `.opencode/`, `.git/`, the Claude, Codex and OpenCode config dirs, the Professor clone's `templates/`) are Claude's alone: no OpenCode agent, gitter included, writes either, and pfm's engine-guard plugin denies each. A deny is a rule, not an obstacle: return the exact change to the user instead of routing around it.
- Executors and probes are the compiled agents; spawn them by name and wait by ending the turn.
- The tiers map to the models `opencode.jsonc` configures for the agents.
