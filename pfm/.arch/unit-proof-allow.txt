# unit-proof allow rows: paths outside the built-in zones a unit test may reach, read by pfm/scripts/unit-proof.sh.
# One row per path: {glob}<TAB>{r|rw|absent}<TAB>{reason}; `*` crosses `/`; an `absent` row allows only a lookup of a
# path that does not exist where the proof runs, so the same probe reads as a reach on a machine holding it; a row
# without a reason fails the proof as ERROR.
/.dockerenv	r	testjail's fence guard (fence.go admitted) stats the container marker before it decides where a binary runs
{checkout}/pfm/*go.mod	r	testjail's profiler (profile.go moduleRootOf) finds the module root by stat-ing go.mod upward from the package directory
/etc/terminfo*	r	the TUI library resolves TERM against the system terminfo database at terminal init (internal/ui), read only and reached through no pfm seam
/lib/terminfo*	r	the same terminfo lookup, its Debian location
/usr/share/terminfo*	r	the same terminfo lookup, its fallback location
/root/extra_*	absent	digest resolve stats a target as a file before it reads it as a Codex agent path, so the golden cases that name /root/extra_N reach the host path first
/root/fix_*	absent	the same file-first stat for the golden agent-path targets /root/fix_*
/.git	absent	project-root discovery (gitroot, workbench, hookentry's git and epic doors) walks up from a test's temp directory and stats .git in every ancestor, the filesystem root last: the walk has no seam that stops it at the temp directory
/tmp/.git	absent	the same upward walk, at the system temp directory that holds every run-made directory
/.professor*	absent	the upward walk for .professor/baseline.json (professor project root, workbench persona) reaching the filesystem root
/tmp/.professor*	absent	the same upward baseline walk, at the system temp directory
/fakegit.json	absent	ancestor walk of the fakegit state lookup above the temp dir (no seam bounds it)
/tmp/fakegit.json	absent	ancestor walk of the fakegit state lookup above the temp dir (no seam bounds it)
/go.mod	absent	testjail Run starts a package in the jail directory (RunInJail), and the profiler (profile.go moduleRootOf) stats go.mod in every ancestor of it, the filesystem root last
/tmp/go.mod	absent	the same upward go.mod walk, at the system temp directory
{checkout}/*.git	r	project-root and git-dir discovery stats .git in every ancestor of the package directory or a checkout-relative cwd; no seam bounds the walk

*/.git/worktrees/*/commondir	r	git-dir resolution of a flight worktree reads the commondir pointer beside its gitfile
