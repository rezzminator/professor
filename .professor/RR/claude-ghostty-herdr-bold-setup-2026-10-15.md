# RR — Most inventive published customizations for Claude Code + Ghostty + Herdr together

Question: map the most inventive customizations people have actually built and published for three tools used together — Claude Code (Anthropic's CLI), the Ghostty terminal, and Herdr (a terminal multiplexer for coding agents) — so the caller can build a bold setup on this machine. Scope: Ghostty shaders/themes/notifications/progress; Claude Code statusLine/spinnerVerbs/output styles/themes/keybindings/hooks/terminalProgressBarEnabled; Herdr config/theming/keys/agent status; cross-tool agent-state-driven visuals.

## Answer

The best ideas use Ghostty's custom shaders, which have had cursor data since [Ghostty 1.2.0](https://ghostty.org/docs/install/release-notes/1-2-0), as a display that responds to agent state. [ghostty-blackhole](https://github.com/s0xDk/ghostty-blackhole) encodes Claude Code's context fill into an OSC 12 cursor color that its shader reads back via `iCurrentCursorColor`, and [ghostty-aura](https://github.com/aparente/ghostty-aura) tints the terminal per hook state, with a ping-pong while working and a hard snap when it needs input. Both write to the terminal device directly, because Claude Code hooks have no controlling terminal and their sanctioned `terminalSequence` output only allows OSC 0/1/2/9/99/777 and BEL ([hooks docs](https://code.claude.com/docs/en/hooks)). The main catch for this three-tool setup is Herdr: it [handles OSC 0/2 and OSC 9 and drops everything else](https://github.com/herdrdev/herdr/issues/5069), and it [reads Claude Code state from the screen](https://herdr.dev/docs/integrations). Cursor-color tricks therefore probably stop at Herdr's pane, and Herdr's own sidebar, plugins and keybind sharing with Ghostty ([Robin Champsaur](https://robinchampsaur.com/writing/ghostty-herdr-agentic-dev-workflow/)) become the state display instead.

## Map

### Ranked novelties (most striking for the effort first)

1. **Cursor-trail shaders**: one `custom-shader` line plus `custom-shader-animation = always`. sahaj-b ships trail effects (`cursor_warp.glsl`, `cursor_sweep.glsl`, `cursor_tail.glsl`) and pulse effects (`sonic_boom_cursor.glsl`, `ripple_cursor.glsl`, `rectangle_boom_cursor.glsl`). Its README says "The solution is to add `custom-shader-animation = always` to your ghostty config" ([sahaj-b/ghostty-cursor-shaders](https://github.com/sahaj-b/ghostty-cursor-shaders)). The reshen gist (after KroneCorylus) uses `iCurrentCursor`, `iTimeCursorChange` and `iCurrentCursorColor` directly ([gist](https://gist.github.com/reshen/991d19f9f8c8fedf64ff726f05f05f44)). Works from 1.2.0 on, but nobody tested it on a current build.
2. **ghostty-aura, agent state tints the terminal**: connected gives an "Animated fade"; working gives an "Animated ping-pong" during tool use; needs_input gives an "Instant snap, holds until resolved"; completed and error each have their own behavior. The page says "tint colors are blended into your base using HSL color math". Per-tab isolation: "When `SessionStart` fires, the hook captures the session's TTY path" and saves it to `/tmp/aura-tty-{session_id}`. It needs OSC 10/11/12 support; the page does not show the exact write sequences ([aparente/ghostty-aura](https://github.com/aparente/ghostty-aura)).
3. **ghostty-blackhole, context fill drives a shader**: it "encodes the context fill into the low nibbles of an amber cursor color (`#f5b000` empty → `#f0bf0a` full)". The page notes that "any program can set the cursor color with a standard OSC 12 escape" and that shaders "_do_ get the cursor color (`iCurrentCursorColor`)". It runs from the statusLine command plus SessionStart and SessionEnd hooks, and finds the pty by walking parent processes because "Claude Code spawns statusLine/hook commands with **no controlling terminal**, so `/dev/tty` fails there". Its stated requirement: "Requires Ghostty 1.3+ (for the cursor shader uniforms)" ([s0xDk/ghostty-blackhole](https://github.com/s0xDk/ghostty-blackhole)). This differs from the release notes, which put cursor data in 1.2.0 (see Ghostty shaders below); `iCurrentCursorColor` may have come later, which is unverified.
4. **Free native signals in Ghostty**: Claude Code's progress bar and desktop notifications. "Ghostty now recognizes the ConEmu OSC 9;4 sequences and renders a GUI native progress bar" ([1.2.0](https://ghostty.org/docs/install/release-notes/1-2-0)), and "By default Claude Code sends a desktop notification only in Ghostty, Kitty, and iTerm2" ([terminal-config](https://code.claude.com/docs/en/terminal-config)). No setup is needed.
5. **State titles**: claude-title shows "`⠋ Working | project` while Claude works" and "`✳ Ready | project` when Claude finishes"; "macOS Ghostty 1.3.1 or later uses its native AppleScript API so title updates cannot split terminal output". Its installer "sets `CLAUDE_CODE_DISABLE_TERMINAL_TITLE=1` in `~/.claude/settings.json`" ([tylerlaprade/claude-title](https://github.com/tylerlaprade/claude-title)). Caveat: that variable also stops OSC 7501 status reporting ([terminal-config](https://code.claude.com/docs/en/terminal-config)). Without it, Claude Code's own OSC 2 writes overwrite titles set by hooks ([#43058](https://github.com/anthropics/claude-code/issues/43058)).
6. **Herdr + Ghostty keyboard and theme fusion**: `keybind = cmd+d=text:\x02v` with "(\x02 = Ctrl+B, Herdr's prefix key)". In his words, "Herdr still thinks I'm a regular `ctrl+b` user, Ghostty just types the prefix for me", and "switching light/dark in Ghostty switches Herdr too" ([Robin Champsaur](https://robinchampsaur.com/writing/ghostty-herdr-agentic-dev-workflow/)).
7. **Sounds and attention**: the official Notification-hook example is `afplay /System/Library/Sounds/Glass.aiff` ([terminal-config](https://code.claude.com/docs/en/terminal-config)). peon-ping plays sounds and sets tab titles such as `● project: done` ([PeonPing/peon-ping](https://github.com/PeonPing/peon-ping)). claude-attention-hooks returns bell plus progress through `terminalSequence` and notes "`bell-features = no-title` drops Ghostty's own 🔔" ([FedorGabrus/claude-attention-hooks](https://github.com/FedorGabrus/claude-attention-hooks)).
8. **Statuslines**: ccstatusline can "Track session cost per hour of active API time or total session time", "Track your progress through 5-hour Claude Code blocks", and has a "`Git PR` widget with clickable PR links" ([sirmalloc/ccstatusline](https://github.com/sirmalloc/ccstatusline)). claude-powerline is "A vim-style powerline statusline for Claude Code with real-time usage tracking, git integration, and custom themes", with a `showPace` option ([Owloops/claude-powerline](https://github.com/Owloops/claude-powerline)). CCometixLine has Directory, Git, Model, Usage, Time, Cost and OutputStyle segments (`unquoted`, [Haleclipse/CCometixLine](https://github.com/Haleclipse/CCometixLine)).
9. **CRT, bloom and background shaders**: `0xhckr/ghostty-shaders` has about 35 shaders, including `bloom.glsl`, `crt.glsl`, `in-game-crt-cursor.glsl`, `vhs.glsl` and `starfield.glsl` ([0xhckr/ghostty-shaders](https://github.com/0xhckr/ghostty-shaders)); see also [m-ahdal/ghostty-shaders](https://github.com/m-ahdal/ghostty-shaders) and [12jihan/ghostty_shaders](https://github.com/12jihan/ghostty_shaders). Whether they still work is unverified.
10. **OSC 7501 per-session status (future)**: "If your terminal implements the OSC 7501 Program Status Protocol, it can show whether each interactive Claude Code session is working, waiting on you, or done", and it "requires Claude Code v2.1.295 or later" ([terminal-config](https://code.claude.com/docs/en/terminal-config)). Ghostty added parsing to libghostty-vt only: "The Ghostty app ignores these reports for now" (merged Oct 6, 2026, [PR #14560](https://github.com/ghostty-org/ghostty/pull/14560)).

### Ghostty shaders
- "Custom shaders to run after the default shaders. This is a file path to a GLSL-syntax shader for all platforms." The uniforms include `iTime`, `iResolution`, `iChannel0`, `iCurrentCursor`, `iPreviousCursor`, `iCurrentCursorColor`, `iTimeCursorChange`, `iFocus`, `iPalette[256]` and `iBackgroundColor` ([config reference](https://ghostty.org/docs/config/reference)). The type of `iFocus` is internally inconsistent in the docs (DISPUTED: the prose describes a float, the declaration says `int`).
- Version: 1.2.0, "released on September 15, 2025", says "Cursor information is now available to custom shaders, enabling custom shaders to do things such as draw cool animations for cursor movement" ([1.2.0](https://ghostty.org/docs/install/release-notes/1-2-0)).
- Cost: `custom-shader-animation` "uses slightly more CPU (generally less than 10%)", while `always` "can become quite expensive" ([config reference](https://ghostty.org/docs/config/reference)). A 1.3.0-dev regression reported idle GPU use at 95% ([#10678](https://github.com/ghostty-org/ghostty/discussions/10678)), bisected to commit f856534 ([#10653](https://github.com/ghostty-org/ghostty/discussions/10653)); whether it is fixed is unknown.

### Ghostty UX features
- Progress: OSC 9;4 native bar in 1.2.0 ([1.2.0](https://ghostty.org/docs/install/release-notes/1-2-0)). "macOS: progress bar widget now renders correctly on macOS 26" ([1.2.1](https://ghostty.org/docs/install/release-notes/1-2-1)). There is "a hardcoded timeout of around 15 seconds, after which the current progress state is reset" ([ConEmu OSC](https://ghostty.org/docs/vt/osc/conemu)).
- Bells: `bell-features` is "Available since: 1.2.0", with `audio` "(Available since 1.3.0 on macOS)"; `bell-audio-path` is available since 1.2.0 on GTK and 1.3.0 on macOS ([config reference](https://ghostty.org/docs/config/reference)).
- In 1.3.0: "Ghostty can now notify you when a long-running command finishes", scrollback search with `cmd+f`, and native scrollbars ([1.3.0](https://ghostty.org/docs/install/release-notes/1-3-0)).
- Quick terminal: the 1.2.0 notes say "The quick terminal is now supported on Linux while running on Wayland" ([1.2.0](https://ghostty.org/docs/install/release-notes/1-2-0)). Theme pairs use `light:theme-name,dark:theme-name`. `background-blur` takes `macos-glass-regular` and `macos-glass-clear` on macOS 26.0 and later ([config reference](https://ghostty.org/docs/config/reference)).
- Claude Code notifications in Ghostty: the claude-code-ghostty hooks "emit an OSC 777 notification sequence", with click-to-focus "verified on Ghostty 1.3.x" ([ishtartec/claude-code-ghostty](https://github.com/ishtartec/claude-code-ghostty)). DISPUTED: discussion [#10215](https://github.com/ghostty-org/ghostty/discussions/10215) reports that notifications did not appear with `preferredNotifChannel` set to `"ghostty"` on 1.2.3.
- Tab color: a maintainer says "We've added tab colors.", but no escape sequence is named ([#10152](https://github.com/ghostty-org/ghostty/discussions/10152)). Driving tab color per state through an escape sequence is unverified.

### Claude Code customization surface
- statusLine: "Your script runs once when a session starts"; "Claude Code debounces updates at 300ms"; `refreshInterval` has a minimum of 1 second; `/statusline` "accepts natural language instructions" ([statusline docs](https://code.claude.com/docs/en/statusline)). Fields on stdin include `cost.total_cost_usd`, `context_window.used_percentage`, `rate_limits.five_hour.used_percentage` and `rate_limits.seven_day.used_percentage` (harvester extraction, [statusline docs](https://code.claude.com/docs/en/statusline)).
- The settings index shows `spinnerVerbs` ("Add or replace the verbs shown while a turn runs"), `spinnerTipsEnabled` ("Hide tips in the spinner while Claude works") and `terminalProgressBarEnabled` ("Hide the terminal progress bar in terminals that support it") ([settings reference](https://code.claude.com/docs/en/settings-reference)).
- Custom themes: "Each custom theme is a JSON file in `~/.claude/themes/`" with `name`, `base` and `overrides`. Tokens include `claude`/`claudeShimmer` (spinner gradient), `promptBorder`, `planMode`, `<color>_FOR_SUBAGENTS_ONLY` and the `rainbow_<color>` ultrathink gradient; the files hot-reload ([terminal-config](https://code.claude.com/docs/en/terminal-config)).
- Output styles live in `~/.claude/output-styles` with frontmatter `name`, `description` and `keep-coding-instructions` ([output-styles](https://code.claude.com/docs/en/output-styles)). Keybindings hot-reload, and chords allow "within 3 seconds" between keys ([keybindings](https://code.claude.com/docs/en/keybindings)).

### Claude Code UX hooks
- "Hooks run without a controlling terminal, so writing escape sequences directly to `/dev/tty` fails." The sanctioned route: "To trigger a desktop notification, set a window title, or ring the bell, return `terminalSequence` instead", which is "Restricted to OSC `0`/`1`/`2`/`9`/`99`/`777` and BEL. If the value contains anything outside the allowlist, the field is ignored." ([hooks](https://code.claude.com/docs/en/hooks)). OSC 12 is not on that list, which is why the cursor-color projects write to the pty directly.
- Notification matchers include `permission_prompt`, `idle_prompt`, `auth_success` and `elicitation_dialog` ([hooks](https://code.claude.com/docs/en/hooks)).
- tmux: "desktop notifications and the progress bar never reach the outer terminal" without `set -g allow-passthrough on` ([terminal-config](https://code.claude.com/docs/en/terminal-config)).

### Herdr
- Repo: [herdrdev/herdr](https://github.com/herdrdev/herdr). The homepage footer reads "v0.9.5 · Apache 2.0" ([herdr.dev](https://herdr.dev)), and the LICENSE file is Apache 2.0 ([LICENSE](https://raw.githubusercontent.com/herdrdev/herdr/master/LICENSE)), which settles bitdoze's AGPL claim. The homepage says "Herdr reads every pane and marks each agent working, blocked or idle" ([herdr.dev](https://herdr.dev)).
- Config: `~/.config/herdr/config.toml`; "The default prefix is `ctrl+b`"; keys are strings like `goto = "prefix+g"`; custom `[[keys.command]]` entries have types `popup`, `pane`, `shell` or `plugin_action`. Theme `terminal` follows the host's ANSI palette, and `auto_switch` defaults to false ([configuration](https://herdr.dev/docs/configuration/)). The default `theme.name` is `"catppuccin"`; there is no documented list of theme names ([config reference](https://herdr.dev/docs/config-reference/)).
- Claude Code detection: "Claude Code state comes from Herdr's screen manifest detection"; "The hook reports Claude Code session identity to the local Herdr socket on session start"; "Install writes `hooks/herdr-agent-state.sh` and updates `settings.json` with Herdr hook entries" ([integrations](https://herdr.dev/docs/integrations)). DISPUTED by bitdoze, which says the SessionStart hook reports progress and completion ([bitdoze](https://www.bitdoze.com/herdr-agent-multiplexer/)). Issue #4009 reports Claude panes stuck at "unknown" on 0.9.0 ([#4009](https://github.com/herdrdev/herdr/issues/4009)).
- Escape-sequence handling: "Herdr v0.9.3's OSC tracking (`src/pane/osc.rs`) handles OSC 0/2 and OSC 9 and drops everything else" ([#5069](https://github.com/herdrdev/herdr/issues/5069)). A title written inside a pane "stops at Herdr", and `ui.toast.delivery = terminal` "asks the outer terminal for a desktop notification" ([config reference](https://herdr.dev/docs/config-reference/)).
- Sidebar tokens: `herdr pane report-metadata <pane_id> --source my-agent-hook --token model=opus --token summary=...` ([config reference](https://herdr.dev/docs/config-reference/)). Socket API: "newline-delimited JSON over a local socket" ([socket-api](https://herdr.dev/docs/socket-api/)).
- Plugins: a `herdr-plugin.toml` manifest ([plugins](https://herdr.dev/docs/plugins/)). Published ones include a sound pack that sets `ui.sound.done_path` and `ui.sound.request_path` ([ezstack-dev/herdr-sound-plugin](https://github.com/ezstack-dev/herdr-sound-plugin)), focus-notify ("clicking a notification activates Ghostty", [yankewei/herdr-focus-notify](https://github.com/yankewei/herdr-focus-notify)), and Tumao's self-report status plugin, a CLAUDE.md convention: "End every turn with `done` or `input`" ([tumao.dev](https://tumao.dev/blog/claude-code-herdr-status-plugin)).

### Cross-tool agent-state visuals
- Verified working designs: ghostty-aura (tints), ghostty-blackhole (shader via OSC 12), claude-title and peon-ping (titles), claude-attention-hooks (bell, progress, dock bounce), and Herdr's sidebar and sound plugins (all above).
- Inference, unverified: under Herdr, the OSC 10/11/12 writes from aura and blackhole land in Herdr's emulated pane and would not reach Ghostty's shader, since Herdr forwards only titles and OSC 9 handling ([#5069](https://github.com/herdrdev/herdr/issues/5069)). No source tested this combination, and no published write-up combines all three tools with state-driven shaders.
