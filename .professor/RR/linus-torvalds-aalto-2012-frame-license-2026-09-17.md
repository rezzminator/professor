# RR — Copyright and license status of the Linus Torvalds Aalto University June 2012 still frame

Question: What is the copyright/licence status of the widely reproduced still frame of Linus Torvalds raising his middle finger at Nvidia during the "Aalto Talk with Linus Torvalds" at Aalto University, Finland, June 14 2012 — the frame taken from Aalto University's own video recording of the talk (published on YouTube by Aalto University). Specifically: (1) under what licence did Aalto University publish that video (Creative Commons? which variant? all rights reserved?); (2) is the frame on Wikimedia Commons, and if so under what licence and with what attribution line; (3) what attribution line would make it safe to embed a 1200×675 crop of that frame in a public open-source README on GitHub, or is it NOT safe to embed at all.

---

## Synthesis

**The original Aalto University YouTube video's license is not documented in publicly accessible sources, the specific still frame is NOT on Wikimedia Commons, and there is no verified attribution or license metadata in any discoverable source — making it unsafe to embed in a public GitHub README without explicit permission from Aalto University.**

### Load-bearing facts

1. **Original video location and creator:** The full "Aalto Talk with Linus Torvalds" was published by Aalto Center for Entrepreneurship (ACE) on their [aaltouniversityace YouTube channel](https://www.youtube.com/watch?v=MShbP3OpASA) on June 14, 2012. The video contains the middle-finger gesture in the Q&A segment.

2. **YouTube license information not publicly stated:** Multiple attempts to locate the Creative Commons license or copyright statement in the video's description failed. YouTube supports only two license types (Standard YouTube License or Creative Commons Attribution), but the specific choice for this video is not documented in web-accessible sources.

3. **Aalto University's institutional licensing policy:** [Aalto recommends CC BY 4.0 for their published content](https://www.aalto.fi/en/open-science-and-research/open-content-licenses-creative-commons), but this institutional preference is not evidence that the 2012 video was licensed under CC BY or any specific Creative Commons variant.

4. **Internet Archive version carries a different license:** The [Internet Archive hosts the talk under CC-BY-NC-SA 3.0](https://archive.org/details/AaltoTalkWithLinusTorvalds), but this is a user-applied tag, not the original Aalto University license statement.

5. **Frame not on Wikimedia Commons:** Direct searches of [Wikimedia Commons' Linus Torvalds category](https://commons.wikimedia.org/wiki/Category:Linus_Torvalds) found 64 media files but none from the Aalto June 2012 event showing the middle-finger gesture. The specific still frame is not discoverable on Wikimedia Commons under any license.

6. **Wikipedia article mentions the event without images:** The [Wikipedia article on Linus Torvalds](https://en.wikipedia.org/wiki/Linus_Torvalds) documents the 2012 Aalto event and the Nvidia statement but contains no image from that specific incident and provides no image credit for a still frame.

### Open questions

- **What license did Aalto University actually apply to the YouTube video?** The video description on YouTube itself is not Web-accessible in my searches; this can only be verified by visiting the video page directly and reading the description field.
- **Does a licensed version of this still frame exist anywhere?** No Wikimedia Commons entry, no Wikipedia image credit, no documented open-source use case with proper attribution was found.
- **What is the safe usage path?** Without a verified license from Aalto University or a licensed copy on Wikimedia Commons, the safest approaches are: (a) contact Aalto University directly for permission and a license statement, or (b) link to the full video on YouTube with a caption rather than embedding the still frame.

### Answer to question (3)

**It is NOT safe to embed a crop of this frame in a public GitHub README without explicit written permission from Aalto University**, because:
- No license is documented on the original source (the YouTube video)
- No licensed version exists on Wikimedia Commons
- No attribution or license metadata is available in any discoverable public source
- Using an unlicensed image from a video exposes a GitHub project to copyright claims

If Aalto University confirms the video is under CC BY 4.0 (or any open license), the attribution line would be: `"Aalto Talk with Linus Torvalds, June 14, 2012, Aalto Center for Entrepreneurship, licensed under [License name]"` — but this must be verified with Aalto first.
