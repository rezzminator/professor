- In every shell command you run (code you write into files is exempt), `rm` gets a literal path, never a variable or substitution, and `rm -rf` an absolute one without a glob: `rm -f /tmp/gate/*.rc` or `rm -rf /tmp/myapp/build`, never `rm -f $L/*.rc`, `rm -rf "$DIR"` or `rm -rf ./build` — an unset variable deletes the wrong tree, and the harness holds the call for a person.
