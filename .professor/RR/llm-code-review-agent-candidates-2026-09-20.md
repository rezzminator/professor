# RR — Is there a downloadable, installable-today open-source LLM code-review agent that implements the evidence-supported review techniques?

Question: is there a DOWNLOADABLE, ready-to-install LLM code-review agent / Claude Code skill / subagent / plugin (open source, installable today) that reviews a local git diff or PR and already implements most of the techniques the evidence supports? Return your standard saved RR map path first, then a cited candidate table.

## Answer

Yes, but only two candidates implement most of the ten boxes *and* run on a local branch range: **SwiftlyAside/review-ledger** (9/10 — Codex-CLI-as-independent-reviewer, deterministic gates that actually run tests, explicit fail-closed; 0 stars, brand new, unproven) and **kodustech/kodus-ai** (7/10 at source — a dedicated `verifier-prompt.ts` that only drops a finding it can actively refute, parallel category agents, adaptive step budget; but it fails open via `Promise.allSettled` and its local CLI path is README-only). No candidate checks every box: **nothing found runs a repro/PoC as evidence except review-ledger's gates and shippie's bash-enabled agentic mode**, and explicit large-diff chunking exists only in Codium-ai/pr-agent and unyieldingclaw's `--chunk` — neither of which pairs it with an independent verifier.

## The map

### Anthropic-official (proprietary licence, mostly PR-bound)

- **anthropics/claude-code `plugins/code-review`** — real two-pass design: "For each issue found in the previous step by agents 3 and 4, launch parallel subagents to validate the issue", genuinely different lenses (CLAUDE.md-compliance sonnet agents / opus bug agents / haiku file-finder), an explicit model-tiering rule, a false-positives skip-list and "We only want HIGH SIGNAL issues". But **box 10 fails at source**: its `allowed-tools` frontmatter is entirely `gh pr view/diff/comment` + inline-comment MCP, with "Use gh CLI to interact with GitHub… Do not use web fetch" — PR-only, no local tree. No test execution, no chunking. [code-review.md](https://raw.githubusercontent.com/anthropics/claude-code/main/plugins/code-review/commands/code-review.md)
- **anthropics/claude-code `plugins/pr-review-toolkit`** — the one official path that *does* run locally: "Run `git diff --name-only` to see modified files", "Agents analyze git diff by default", `gh pr view` only to detect an existing PR. Six distinct-lens agents (comment-analyzer, pr-test-analyzer, silent-failure-hunter, type-design-analyzer, code-reviewer, code-simplifier), each self-scoring 0-100. **No separate verification pass** — the finder is the scorer, so boxes 1, 2 and 9 fail. Last touched Oct 9 2025. [review-pr.md](https://raw.githubusercontent.com/anthropics/claude-code/main/plugins/pr-review-toolkit/commands/review-pr.md), [commits](https://github.com/anthropics/claude-code/commits/main/plugins/pr-review-toolkit)
- **Licence caveat**: the `anthropics/claude-code` repo is **not open source** — "© Anthropic PBC. All rights reserved. Use is subject to Anthropic's Commercial Terms of Service". [LICENSE.md](https://raw.githubusercontent.com/anthropics/claude-code/main/LICENSE.md)
- **anthropics/claude-code-security-review** (MIT, ~6.3k stars) — has a genuine separate FP-filter (`FindingsFilter.filter_findings()` → `analyze_single_finding()`), strong noise control ("MINIMIZE FALSE POSITIVES", "Focus on HIGH and MEDIUM findings only", `"line": 42`). But it **fails box 9 twice**: "Below 0.7: Don't report" is a self-reported-confidence gate, and on API failure the filter keeps findings with `confidence_score: 10.0`. Worse, **issue #139 confirmed at source**: `validate_api_access()` hardcodes the retired `claude-3-5-haiku-20241022`, and when that health check fails `FindingsFilter` silently sets `use_claude_filtering = False` — the FP pass turns itself off invisibly. Default model is `claude-opus-4-1`. **No local mode at all**: no argparse/CLI entrypoint; config comes only from `GITHUB_REPOSITORY`/`PR_NUMBER` env vars. [prompts.py](https://raw.githubusercontent.com/anthropics/claude-code-security-review/main/claudecode/prompts.py), [findings_filter.py](https://raw.githubusercontent.com/anthropics/claude-code-security-review/main/claudecode/findings_filter.py), [issue #139](https://github.com/anthropics/claude-code-security-review/issues/139)
- **anthropics/claude-code-action** — not a reviewer. "prepare → install Claude → run Claude once → update comment with results. There is no post-processing, filtering, or re-validation." It is a harness that could carry any of the above prompts. [run.ts](https://github.com/anthropics/claude-code-action/blob/main/src/entrypoints/run.ts)

### Strongest local-diff candidates

- **SwiftlyAside/review-ledger** (MIT, 0 stars, last commit 2026-09-11; needs Node ≥20 + Codex CLI ≥0.153) — the only candidate with a *cross-family* verifier as a real subprocess: `codex exec -m gpt-5.6-sol -c model_reasoning_effort="xhigh" -s read-only -C "$REPO"`. Ledger forces a per-finding author reply where "'fixed' is not evidence — the command and its result are". Deterministic gates run "tests, linters, budget checks" before each round (box 4 — unique among candidates). Fail-closed: "Reviewer failure, timeout… or a schema mismatch is not a round: retried once, then escalate". Severity floor: "Only blocking severities (default P0, P1) hold the loop". Layered rubrics = different lenses. Tiering stated (`effort_round` medium, `effort_reopen` high, R1 xhigh). Local: `RL open [--base <ref>]` → `git diff $(git merge-base <base> HEAD)`. Weak box 6: oversized diffs "drop file bodies, then abort", no true chunking; **uncommitted work is not reviewed** ("Commit before open"). Cost: unverified beyond a ~20K-input-token round estimate. [docs/protocol.md](https://github.com/SwiftlyAside/review-ledger/blob/main/docs/protocol.md)
- **kodustech/kodus-ai** (AGPLv3 core + enterprise EE, ~1.4k stars) — dedicated verifier prompt: "verify ONE candidate finding: confirm or REFUTE its technical claim… DROP the finding ONLY if you can actively REFUTE it" — a correct burden-of-proof inversion. Parallel category agents (bug/security/performance/generalist/kody-rules). Adaptive budget: "0.5 steps per extra file beyond an 8-file baseline, capped at 100 steps" plus compact/full prompt variants. Context: trace decisions, prior suggestions, Kody rules, coverage tiers. **Fails open** — `Promise.allSettled()` returns partial results when agents fail. No test execution. CLAUDE.md/AGENTS.md ingestion UNVERIFIED. Local `kodus review` on working tree/staged/branch/commit is a **CLI-README claim, source not read**. [prompt-builder.ts](https://github.com/kodustech/kodus-ai/blob/main/libs/code-review/infrastructure/agents/prompts/prompt-builder.ts), [verifier-prompt.ts](https://github.com/kodustech/kodus-ai/blob/main/libs/code-review/infrastructure/agents/prompts/verifier-prompt.ts), [review-orchestrator.service.ts](https://github.com/kodustech/kodus-ai/blob/main/libs/code-review/infrastructure/agents/review-orchestrator.service.ts)
- **husnuguner/code-reviewer** (MIT, 0 stars, `bun install -g github:husnuguner/code-reviewer`) — honest second pass, source-confirmed: "a second model call that removes findings the diff itself refutes. It may only remove, never edit, **and fails open**"; `failOpen()` returns `keepAll()` on any exception or unparseable reply. Anchor repair also degrades rather than drops. Good noise control (`--fail-on`, `--exclude`, per-file caps, auto-skipped credential files, verbatim-quote anchoring). Local: `BranchReviewOptions {base, branch}` + `uncommitted` vs HEAD. Same model does both passes → box 2 no. [verify.ts](https://raw.githubusercontent.com/husnuguner/code-reviewer/main/src/core/review/verify.ts), [branch-review.ts](https://raw.githubusercontent.com/husnuguner/code-reviewer/main/src/core/review/branch-review.ts)
- **calimero-network/ai-code-reviewer** (MIT, 9 stars) — local mode confirmed at source: `--staged` ("Review the index instead of the working tree"), `--base` ("Review base...HEAD"), `review_local(root=os.getcwd(), ...)`. Consensus rather than verification: `--min-agreement` FloatRange default `2/3`, agents capped 1-5 (default 3) — the finders vote on each other, so box 2 is no. Five distinct lenses (security/performance/patterns/logic on Sonnet, style on Haiku). No test execution found in `cli.py`. Stated doc-path cost "~$0.05–0.15 per merge". [cli.py](https://raw.githubusercontent.com/calimero-network/ai-code-reviewer/master/src/ai_reviewer/cli.py)
- **unyieldingclaw-dev/ai-code-review-agent** (MIT, 2 stars, npm global, **$0 — Ollama-local**) — the only candidate checking boxes 3, 6, 7 and 8 together: 15 isolated specialist agents ("agents don't bias each other"), `--chunk` full-coverage passes, named profiles `fast`/`full`/`change-review` as an explicit tiering rule, `--fail-on` floor + `.aiignore`. Optional `--verify-evidence` runs a *different* model (qwen3) over Critical/High findings — but it is off by default and report-only, and the tool self-describes "Self-report only — each agent sets its own 0–100 confidence… fails open". [repo](https://github.com/unyieldingclaw-dev/ai-code-review-agent)

### Box-level cross-cutting findings

- **Box 4 (execution evidence)** — looked across all 18 candidates and found it in exactly one by design (review-ledger's deterministic gates) and one by capability (shippie's bash tool). Anthropic's own plugin, kodus, AppVerk and calimero all explicitly do not run anything.
- **Box 6 (large-diff decomposition)** — found in pr-agent (`_prepare_chunked_prediction`) and unyieldingclaw (`--chunk`) only; review-ledger drops-then-aborts; every Claude Code plugin/skill examined has no chunking rule whatsoever. This is the most widely unsolved box.
- **Box 9 (no self-confidence-only, no fail-open)** — only review-ledger is explicitly fail-closed. husnuguner, unyieldingclaw, kodus and claude-code-security-review all fail open by documented design.
- **Box 2 (independent verifier)** — only review-ledger (different model family, separate process) and kodus (separate verifier prompt, same family) qualify; the official Anthropic plugin qualifies on fresh-subagent grounds but is PR-only.
