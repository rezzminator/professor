# v0.83.0 — 2026-10-27

Herdr becomes a native seat for pfm chats, pfm themes sync one palette across Claude Code, Herdr, VS Code and Ghostty, sub-agent-compact is renamed forward-compaction, and Professor ships no GPT agents. This release skipped the area review and the update rehearsal; read `## Verification` before updating.

## Breaking

- Global: forward-compaction — the sub-agent-compact plugin is renamed forward-compaction across Professor; its submodule moves to `plugins/forward-compaction`, and every agent, hook and config reference uses the new name.
- Global: no GPT agents — Professor ships no GPT agent twins; `claude.gptAgents` remains only as a switch.
- Project: pruned project templates — `pfm init` no longer scaffolds the project `CLAUDE.md`, the per-project and build docs, the mentor, marketer and officer agents, the Codex skills, or the dev, drain-wait and memory scripts; `pfm doctor --project-updates` reports what an adopter still holds of them.

## Added

- pfm: native Herdr seat — pfm detects Herdr and runs its own seat host instead of tmux; each Herdr tab shows its chat's live status, name and resume command, and the `pfm ls` picker opens chats in Herdr tabs.
- pfm: theme sync — every pfm theme is one JSON file under `templates/themes/`; `pfm theme list|use` syncs one palette across Claude Code, pfm tmux, Herdr, VS Code and Ghostty, on macOS and on Linux with VS Code Remote-SSH; the Tokyo Night profile ships as `tokyo-night`.
- pfm: `pfm restart` — ends every chat, restarts Herdr and every pfm service and daemon, each verified up.
- pfm: broadcast calls — `pfm chat call` and the MCP `call` tool send to several targets at once.
- pfm: extensions switch — `extensions` in `pfm.config.json` admits third-party agent plugins.
- Global: chatlog kit — a modular stdlib package, native on Claude Code, Codex and OpenCode, with `census`, `metrics`, `waits` and `entry` verbs.
- Global: /dude skill — a machine-global course-correction skill naming ten recurring failure patterns.
- Global: cache-keepwarm plugin — joins the marketplace; keep-warm pokes with a per-wait cap and a status-line session shield.
- Repo: fence knobs — every test and gate knob is a validated env var, with a native host profile.

## Changed

- Global: flights — one lander with a computed fan-out replaces the three lander tiers; `flights-speccer` returns as a user-requested agent.
- Global: auto-effort-control — replaces the auto-effort and effort-live-control plugins; the status line's effort segment reads its mode and level.
- Global: themer — owns the theme pipeline end to end, replacing `/imagine-professor-theme`.
- Global: imagine — the family collapses to `/imagine`, the imaginator agent and the `ultimate` skill.
- Global: context audit — one user-only initial-context audit replaces the context-meter and context-audit commands.
- Global: agent-investigator — transcript investigation runs on the chatlog kit and replaces chat-investigator.
- pfm: fleet prompts — compose at install time; `composed/` is no longer tracked.
- pfm: Codex launches — every Codex chat pfm launches runs in-process with `--no-daemon`, unless the user's own arguments choose otherwise.
- Repo: plugins — every marketplace plugin points at a published release: engine-sync v0.5.0, callmeter v0.4.5, cache-live-control 0.6.5, cache-keepwarm 0.5.0 (its first release), buddy 3.0.1, harvester 0.1.0, tool-visibility-controller 0.3.6, auto-effort-control 1.0.0 and forward-compaction 1.0.0; the marketplace installs harvester from its `main` branch.

## Fixed

- pfm: update from v0.82.0 — `pfm install` and `pfm doctor` accept the retired `--skip-harvest` flag as a no-op with a one-line notice, so a v0.82.0 updater that passes it no longer rolls back.
- pfm: flights-speccer — the retired-name scan and `pfm doctor` no longer report the shipped `flights-speccer` agent as retired.
- pfm: leftover harvester settings — `pfm doctor` warns on a leftover `harvester.config.json` and on an `mcp.servers.harvester` entry, each with the action that clears it.
- pfm: fixes — 126 fix commits since v0.82.0, led by pfm (24), Herdr (16), the status line (11), chatlog (8), themes (6) and the fence (6); `git log --oneline v0.82.0..v0.83.0` lists them.
